# Архитектура

Приложение является статическим Vue SPA для GitHub Pages.
Один экран показывает одну вертикальную карточку на всю доступную высоту.
На широком экране область карточки располагается по центру и сохраняет портретные пропорции.

## Границы

- `app` создаёт Vue и Pinia и подключает общие стили.
- `pages/weather` собирает главный экран из нижних слоёв.
- `entities/weather` содержит чистую модель сетки и её реактивное хранилище.
- `shared` содержит независимые ресурсы, темы и общие компоненты.

Импорты других срезов используют публичный `index.ts` через псевдоним `@/`.
Код нижнего слоя не импортирует верхний. Тесты имеют доступ к публичным API всех слоёв.

`WeatherGrid` совместим с типом `Grid` пакета TikiTaki. Движок свайпов будет
подключён во втором этапе через опубликованный Vue адаптер и шаблонный `Teleport`.
Код библиотеки не копируется и не подключается по абсолютному пути.

## Модель сетки

`createWeatherGrid` получает фиксированное время, часовой пояс местоположения
и список доступных дней с реальными часовыми метками. Результат содержит
неизменяемые описатели текущей погоды, дневной сводки и часового прогноза.

Первый снимок содержит только текущую ячейку. Дни добавляются по мере получения
сведений о горизонте API. Дни без часов остаются строками из одной сводки.
Идентификаторы зависят от местной даты, вида ячейки и абсолютной временной метки.

Даты вычисляются через `Intl.DateTimeFormat` с явно переданным часовым поясом.
Разбор строк дат через системную культуру не используется.
Границы суток, пропущенные и повторившиеся часы учитываются по реальным меткам API.

Число строк определяется данными. Ограничение текущего тарифа поставщика
будет применяться его адаптером, а не интерфейсом или константой в сетке.

`useWeatherGridStore` атомарно заменяет корректный снимок. Некорректное обновление
сохраняет предыдущий снимок. Начальный UTC является техническим значением до
подключения геолокации и не должен использоваться для будущих API запросов.

## Ресурсы

На первом этапе подключены русские и английские строки стартового экрана
и ошибок модели, а также нейтральные цвета из AvaWeather.
Страница пока использует русский язык. Автоматический выбор языка и полный
перенос погодных тем, Inter и иконок входят в следующие этапы.

Bootstrap подключается через Sass `@use`. Импортируются только корневые стили,
сброс оформления, спиннер и вспомогательные стили скрытого доступного текста.
JavaScript плагины Bootstrap стартовому экрану не нужны.
