# Этапы разработки

1. Готово — каркас Vue SPA, FSD, строгий TypeScript, Pinia, проверки и модель сетки через TDD.
2. Готово — подключение TikiTaki и Vue адаптера, свайпы и жизненный цикл карточек.
3. Реализовано — геопозиция устройства с резервом GeoJS, быстрая загрузка текущей погоды,
   карточка A1, ошибки и повтор. Для работы с настоящим WeatherAPI нужен `WEATHER_API_KEY`.
4. Фоновая загрузка прогноза и приоритет открытой ячейки.
5. Резервные поставщики Open Meteo и OpenWeatherMap после WeatherAPI.
6. Полный перенос тем, Inter, SVG иконок и локализации AvaWeather.
7. Проверки на реальном телефоне и публикация рабочего прогноза на GitHub Pages.

Каждый этап проходит падающие тесты, минимальную реализацию, рефакторинг
и проверки. Изменения сохраняются промежуточными коммитами.

Инфраструктура GitHub Actions и Pages настроена, первый этап опубликован.
Сборка получает ключ WeatherAPI из секрета `WEATHER_API_KEY` этого репозитория.
