# Этапы разработки

1. Готово — каркас Vue SPA, FSD, строгий TypeScript, Pinia, проверки и модель сетки через TDD.
2. Готово — подключение TikiTaki и Vue адаптера, свайпы и жизненный цикл карточек.
3. Готово — геопозиция устройства с резервом GeoJS, быстрая загрузка текущей погоды,
   карточка A1, ошибки и повтор.
4. Готово — фоновая загрузка дневного и почасового прогноза, приоритет выбранного дня,
   спиннеры пустых ячеек и повтор после ошибки.
5. Готово — резервные поставщики Open Meteo и OpenWeatherMap после WeatherAPI.
6. Готово — перенос погодной палитры, четырёх начертаний Inter, SVG иконок,
   значка приложения и локализации AvaWeather.
7. Проверки на реальном телефоне.

Каждый этап проходит падающие тесты, минимальную реализацию, рефакторинг
и проверки. Изменения сохраняются промежуточными коммитами.

Инфраструктура GitHub Actions и Pages настроена, предыдущие этапы опубликованы.
Сборка получает ключи из секретов `WEATHER_API_KEY` и `OPENWEATHERMAP_API_KEY`
этого репозитория. Open Meteo не требует ключа.
